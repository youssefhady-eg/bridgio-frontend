BRIDGIO fonts — install before opening the deck
Sora = Latin display (Bold/SemiBold static + variable), Nunito = Latin body, Alexandria = Arabic display, Baloo Bhaijaan 2 = Arabic body. All OFL, free. No Fredoka — removed by decision.
Windows: select all .ttf files > right-click > Install.
Then open BRIDGIO_Brand_Guidelines_v1.2.pptx in PowerPoint and Save As with "Embed fonts in the file" checked, so the deck travels with its fonts.
