# BRIDGIO — Frontend (internal MVP)

Arabic-first BRIDGIO product frontend on top of Mentingo (headless API / DB /
auth / courses). `main` is at `2135fb1`: Stages 0–5 are merged, and Stage 6
(consistency polish) is merged via PR #10. The Stage 0 API adapter contract is in
place; the dashboard, teacher builder and student player are the built product
screens, and every other nav destination still opens a labelled placeholder.

> **Status: PROPOSED only.** Mentingo's local source was deleted by the owner on
> 2026-11-01, so there are **no confirmed Mentingo endpoints** in this build.
> Every adapter method and HTTP path is labelled “PROPOSED — Mentingo to
> implement on restore/rebuild”. This build is not locked, final, or
> externally ready.

## Stack

- TanStack Start + TanStack Router + TanStack Query
- TypeScript, Vite
- Arabic-first, full RTL, light theme only
- Mock adapter by default; real backend via configuration

## Requirements

- Node.js **>= 22.12** (Vite 8 requirement; developed on Node 24)
- npm

## Quick start

```bash
npm install
npm run dev
```

Open `http://localhost:3000/`. With the default teacher role, `/` redirects to
the Stage 2 dashboard at `/teacher/dashboard`. Append `?as=student` to see the
Stage 1 shell overview instead; the switch is diagnostic UI state, not auth.
Use `VITE_MOCK_SCENARIO=empty npm run dev` for the empty-state dashboard.

## Configuration

Copy `.env.example` to `.env` only if you need different values. `.env` is
git-ignored. Never commit a secret or token.

| Variable | Default | Purpose |
| --- | --- | --- |
| `VITE_API_ADAPTER` | `mock` | `mock` or `http` |
| `VITE_API_URL` | `http://localhost:3001/api/v1` | **PROPOSED** Mentingo base URL (http mode only) |
| `VITE_MOCK_SCENARIO` | `seeded` | `seeded` or `empty` |
| `VITE_MOCK_SESSION` | `teacher` | `teacher`, `student`, `none` (mock only) |
| `VITE_SHOW_DEV_CHROME` | shown | `false` hides the stage banner, build notes and preview-role switcher (user-facing build) |
| `VITE_API_TIMEOUT_MS` | `15000` | HTTP timeout |

Switching from mock to a real backend is a configuration change, not a screen
rewrite.

## Rules that matter

- No component calls `fetch` or hard-codes persistent data.
- The mock and HTTP adapters share one interface, method names and shapes.
- Mentingo owns auth, users and roles. No BRIDGIO auth/user/role system.
- Mohsen answers only from teacher material + fixed curriculum and always shows
  grounding. If it does not know, it says so.
- No intelligent marking, price, installments, Learn-to-Hire, exotic-language
  flows or dark theme in this MVP.
- Arabic copy is draft and centralised; BRIDGIO / Mohsen are working names.
- No paid service, library, font or image.
